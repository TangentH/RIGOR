# Grounded-SAM-2 runtime subset

This directory contains the public SAM 2/Grounding DINO runtime files used by
the HILTI workflow. Upstream notebooks, web demos, training utilities, datasets,
and showcase media are omitted to keep the repository focused on inference and
reproducibility. The original upstream licenses are retained in this directory.

The project entry point is `tools/hilti_person_mask_batch.py`.
